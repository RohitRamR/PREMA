PREMA HUMAN FACTORS RULE

Every user-facing screen must be evaluated through:
1. Cognitive load
2. Decision fatigue
3. Attention hierarchy
4. Working-memory limitations
5. Visual perception
6. Touch ergonomics
7. Motor accessibility
8. Reading effort
9. Emotional state
10. Trust
11. Error prevention
12. Recovery effort
13. Information density
14. Choice architecture
15. Perceived performance

For every important interaction ask:
- What does the user need to understand?
- What decision are they making?
- What information is essential?
- What can be deferred?
- What is the user's likely emotional state?
- How many choices are presented?
- How much working memory is required?
- Can the primary action be comfortably reached with one hand?
- Can a user understand the next action without reading a large paragraph?
- What happens if the user makes a mistake?
- Can the user recover easily?
- Does the design create unnecessary pressure?
- Does the UI exploit anxiety, loneliness, urgency or fear?
- Does the screen communicate trust appropriately?

PREMA must optimize for confident decisions, not compulsive engagement.

Use evidence-based principles such as:
- Fitts's Law
- Hick's Law
- Miller's Law
- Jakob's Law
- Gestalt principles
- Peak-End Rule
- Serial Position
- Von Restorff Effect
- Nielsen's usability heuristics
- Progressive disclosure
- Cognitive load reduction
- Recognition over recall

For mobile interfaces additionally consider:
- Thumb reach
- Touch target size
- Gesture discoverability
- One-handed use
- Dynamic text
- Screen-reader navigation
- Reduced motion
- Haptics
- Platform conventions
- Visual acuity
- Contrast
- Fatigue

Never use psychological principles to manipulate users. Usability > Honesty > Persuasion.

PREMA must never exploit loneliness, fear of missing out, romantic insecurity, artificial scarcity or emotional vulnerability to increase engagement or payment.

The target UX is:
CALM
CLEAR
CONFIDENT
TRUSTWORTHY
EASY TO USE
EMOTIONALLY INTELLIGENT
